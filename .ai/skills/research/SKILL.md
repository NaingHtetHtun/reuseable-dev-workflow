# Research Skill

## Purpose
Research external technologies using official sources before implementing.

## When to Use
- Before integrating a new library
- Before using a new API
- Before implementing a protocol
- When current documentation is uncertain

## Required Behavior
1. Start with official documentation.
2. Check the official repository.
3. Verify the current version.
4. Do not rely on random tutorials.
5. Record the documentation reference.
6. Note version-specific behavior.

## Priority Order
1. Official documentation
2. Official repository
3. Official package docs
4. High-quality technical references

## Things to Inspect
- Official docs URL
- Current stable version
- Breaking changes in recent versions
- Community adoption and maintenance status

## Things to Avoid
- Copying code from random blog posts
- Assuming API behavior from memory
- Using outdated documentation
- Ignoring breaking changes
- Not recording references

## Verification Checklist
- [ ] Official docs consulted
- [ ] Current version verified
- [ ] Breaking changes checked
- [ ] Reference recorded in feature doc
