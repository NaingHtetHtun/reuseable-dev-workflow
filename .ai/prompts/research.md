# Research Prompt

## Instructions for AI Agent

You are researching an external technology, library, or API.

### Step 1 — Official Sources
- Find the official documentation URL.
- Find the official repository.
- Identify the current stable version.

### Step 2 — Key Information
- Core concepts and API surface
- Installation and setup
- Configuration options
- Common patterns
- Known limitations
- Breaking changes in recent versions
- License

### Step 3 — Compatibility
- Does it work with our TypeScript version?
- Does it work with our Node version?
- Does it conflict with existing dependencies?
- Is it maintained and active?

### Step 4 — Report
Provide a structured summary:
- What it is
- Current version
- Key API/features relevant to our use case
- Installation command
- Compatibility assessment
- License
- Recommendation: USE / AVOID / INVESTIGATE_FURTHER
- Official docs reference URL

### Step 5 — Record
If the research supports a feature, include the reference in the feature documentation.
