# Refactor Prompt

## Instructions for AI Agent

You are refactoring existing code. Follow these steps.

### Step 1 — Understand
- Read the code to be refactored.
- Understand what it does and why.
- Check for existing tests.

### Step 2 — Ensure Safety
- Verify tests exist for the code being refactored.
- If no tests exist, write them first.
- Run tests to confirm they pass.

### Step 3 — Plan
- Explain what will change and why.
- Explain what will NOT change (behavior).
- Identify risks.

### Step 4 — Implement
- Refactor in small, verifiable steps.
- Run tests after each step.
- Do not change behavior.
- Do not add features.

### Step 5 — Verify
- All tests pass.
- Typecheck passes.
- Lint passes.
- Code is measurably improved.

### Step 6 — Document
- Update documentation if module structure changed.
- Note the refactor in commit message.
